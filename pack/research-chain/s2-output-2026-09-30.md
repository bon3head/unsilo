## Wayback CDX
- Endpoint web.archive.org/cdx/search/cdx, url= required. Fields: urlkey, timestamp,
  original, mimetype, statuscode, digest, length.
- matchType: exact (one URL) / prefix (path tree, default broad scope) / host (whole
  host only if careers-only) / domain (subhosts too; only if entire space in scope).
  Delegated ATS namespaces queried separately.
- from/to inclusive, 1–14 digits. filter/collapse are LOSSY: collapse=digest only
  collapses adjacent matches; status filtering deletes rows (200/301/404 all real).
  Raw enumeration: no filter, no collapse.
- Exhaustion: showResumeKey/resumeKey until no key returned. page=/showNumPages has
  documented freshness caveat — resume-key traversal preferred. No snapshot-isolation
  guarantee across multi-request traversal.
- Fair access: identifying UA + 429/Retry-After; numeric ceiling UNKNOWN.
- Strongest valid claim: "all publicly returned rows matching Q,W, continuation
  exhausted, as observed at T". Not web/archive exhaustiveness (IA documents crawl,
  robots, auth, JS, owner-exclusion gaps; CDX has access-control facility).
