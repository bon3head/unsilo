# S5 output — B7 schema/vocabulary + B8 identity registry FROZEN (distilled 2026-09-30 ~7:50 PM ET)

## B7: three distinct versioned objects
- **Schema** = logical result contract (fields, types, cardinalities, relationships,
  temporal roles, claim semantics). Not publisher words, not DDL.
- **Vocabulary** = frozen concept/term set with definitions + admission profile for
  external publisher terms (W3C SKOS "concept scheme").
- **Classification** = frozen assignment function from observed values to analytic
  concepts (inputs, rules, precedence, exclusions, abstain behavior).
- Independent immutable versions; only affected axis advances (B7.1/B7.2).
- **No retroactive reinterpretation (B7.3):** result under (S3,V2,C2,R17) stays that
  forever; recomputation under new pins = new result. Grounded in multitemporal
  schema versioning (De Castro et al. — historical schema interfaces retained).
- Result interpreted under pin vector P = (S,V,C,R).

## Vocabulary admission
- Schema.org JobPosting = publisher vocabulary, never UnSilo's schema.
- Frozen readings: datePosted → publisher-declared publication time (day-granular if
  date-only); validThrough → publisher validity assertion (not a closure event);
  title/description → raw observed strings; department labels → raw, no normalization.
- Correction: Schema.org JobPosting has NO literal `department` property — it has
  `employmentUnit`; Lever has categories.department; Greenhouse has its own.
  B7.4: never silently rewrite one as another without frozen mapping.
- B7.5: inferred categories enter results ONLY through a frozen classifier with a
  published mapping. No ad-hoc regex, no LLM labeling, no analyst intuition.
- B7.6: external vocabularies pinned by release (Schema.org 30.1 as of 2026-09-16;
  30.0 added jobDuration to JobPosting — kills "Schema.org is stable enough").
  Providers without release numbers → UnSilo's own vocabulary/source-contract version.

## B8: identity registry (evidence-backed, exact-only, bitemporal)
- Canonical: 10-digit CIK where the recruiting publisher IS the filer. Parent's CIK
  never inherited by a subsidiary/brand without evidence.
- Non-filer: opaque durable UnSilo company ID. Prohibited as canonical keys:
  names, ticker, domain, URLs, Greenhouse token, Lever SITE.
- B8.1: ticker = time-sensitive locator; Resolve(ticker,T,K) through registry at cut.
- **PublisherIdentityBinding**: evidence artifact asserting company C exposed provider
  P during effective interval E, known by cut K. Exact provenance chain required
  (e.g., first-party page linking the board). Plausible brand strings ≠ evidence.
- B8.2: NO probabilistic company matching in v1 (Fellegi-Sunter deliberately
  excluded). Exact CIK / exact registry resolution / exact binding / exact continuity
  evidence, else UNRESOLVED.
- B8.3: every identity assertion carries evidence + registry version, or it is not a claim.
- B8.4: Registry@K = closed assertion set known at K. Resolve(locator,T,K).
  Corrections never rewrite earlier cuts. Rename: same CIK + name change = same
  identity with name history; non-filer rename needs exact continuity evidence, else
  unresolved.
- Cross-version comparison: must declare both (S,V,C,R) vectors and the delta.
  Declaring ≠ proving comparability — B2 owns that.

## Change taxonomy
Version-forcing: field add/remove/redefine; term add/remove/redefine; admitted-external-
term meaning change; classification rule/precedence/fallback change; identity mapping
or binding-interval change; identity correction; provider contract field change
(+ vocabulary version if admitted semantics changed; schema only if result contract
changed). NOT version-forcing: new observations in existing fields; new raw label in
an existing open-text field (unless classifier extended); rendering/spelling/display
fixes; report reformatting with identical populations/meaning.
