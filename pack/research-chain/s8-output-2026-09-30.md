## B1: closed query model
- Q = ⟨φ, G, Ω, Ke, Kk, P, Ξ⟩: typed predicate over PRS; declared analytic grain G;
  scope Ω = (source set, company set, window); effective cut Ke; knowledge cut Kk;
  immutable pin vector P = (S_schema, V_vocabulary, C_classification, R_registry);
  evidence-class expectations Ξ.
- Closure rule: ¬Closed(Q) ⇒ REJECT before canonical data is touched.
- No implicit defaults: no "current" schema/classifier/registry, no "all
  companies", no "all sources", no "latest", no wall clock, no local timezone, no
  default evidence policy, no default grain. UNBOUNDED must be explicit; blank ≠
  UNBOUNDED. Missing field = malformed (not UNKNOWN).
- "Serializable" = semantic losslessness required; concrete format is build work.

## Common operator outcome contract
- Outcome<T> = VALUE(T) | UR(reason); pre-execution/static = REJECT(reason).
  Never collapse: VALUE(∅)/0 are legitimate values; UR = admissible but
  unjustifyable; REJECT = not a legal computation. A stored SQL NULL is neither
  UR nor REJECT.

## B9: six-operator algebra (complete for the v1 question family)
Rel<T,G,P,Ω,Te,Tk>: rows of type T, grain G, pins P, scope Ω, effective shape Te,
knowledge shape Tk. Point vs interval are distinct types — no implicit coercion.
- Enumerate: PRS[P]×Ω×φ×Ξ → Outcome<Rel<Evidence,G,P,Ω,Uncut,Uncut>>. Items keep
  PD/AO/DD classes. Empty enumeration ≠ QN.
- RestrictTime: ×Ke×Kk → applies cuts independently. Class-preserving. Required
  UNKNOWN bound changing membership → UR. UNBOUNDED ≠ UR. Missing cut/"now" → REJECT.
- Classify_C: pinned classifier, exact temporal-type match. No evidence-class
  promotion; carries input support classes. Undecidable required label → UR.
  Wrong version / nondeterministic classifier → REJECT.
- Aggregate_a: ×FanoutProof<Gin→Gq> → at declared grain Gq only. Carries support
  envelope; creates no stronger class. UR: required input UR, unknown
  denominator/population, unclosable B10 dep. REJECT: missing fanout proof,
  output grain ≠ declared grain, forbidden numerics.
- Difference: X@Cut₁ × X@Cut₂ → Delta<X>@{Cut₁,Cut₂}. Identical non-temporal
  semantics required (type, predicate, grain, scope, pins, evidence contract).
  State delta, not world disappearance. Carries both evidence envelopes. Difference
  does not manufacture QN. One cut → REJECT; more than two → REJECT.
- QN (qualified negation): QN(φ,Q) ⟺ CompleteWithinScope(Q) ∧ ZeroMatches(φ,Q) ∧
  TemporalAdmissible(φ,Q). Emits QN(witness) or UR(reason). Never bare false.
  Nonzero zero-check surfaced as counterevidence under B12. Evidence-admission
  operator, not Boolean negation.

## Static composition
- g∘f legal only on exact output→input type match. No implicit coercions
  (point↔interval, grain conversion, version rebinding, class
  weakening/strengthening, UNKNOWN→UNBOUNDED, nullable→UR).
- Operator order is semantic; no general commutativity. Aggregate(Classify(x)) ≠
  Classify(Aggregate(x)) in general. Rewrites require proved equivalence over
  value, classes, pins, cuts, closure, B12 disclosures.

## No-string-query rule
- No ad-hoc SQL/NL/text as executable analytic queries. Every analytic computation
  = operator composition under closed Q. SQL may be a future internal execution
  substrate, never the semantic interface. Raw SQL run against canonical tables is
  not a valid UnSilo analytic result. "What changed at AMD?" is query-construction
  input, not executable semantics.

## B10 emitter obligation = operator semantics
- Every operator is conceptually (A,Dep_in) → Outcome(B, Dep_in ∪ DepFrag_op).
  A VALUE without its dependency fragment is invalid.
- Fragment must expose: admitted evidence + receipts, full pin vector, grain,
  scope + cuts consumed, operator identity + parameters, proofs/witnesses
  (fanout proofs, completeness witnesses).
- QN: empty evidence set insufficient — fragment must carry scope-exhaustion deps,
  executed zero-check, temporal admissibility. Difference: both cuts' deps.
- Composed result: Dep(r) = lfp(⋃ DepFrag_op_i).
- "Log provenance afterward" is INVALID. Operator def without B10 emission ≠ v1
  operator. Valid operator hitting an unreceipted dep during legal execution →
  cannot emit VALUE (UR/unreproducible under B10).

## Determinism
- Eval(E, Dep) = CanonicalResult: same composition + same closed Dep ⇒ identical
  canonical result (value, classes, pins, cuts, grain, dependency identity).
- Ambient-state-dependent operators inadmissible: wall clock, implicit current/
  latest, retrieval order, hash-map iteration, locale/timezone, unseeded random,
  unreceipted network state. "Today" enters only via declared cut/parameter.
