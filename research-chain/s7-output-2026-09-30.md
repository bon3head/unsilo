## B10: dependency closure
- Dep(r) = least fixed point of transitive dependency relation over mandatory
  classes: E_r (admitted evidence + Session-2 receipts; receipt contract NOT
  redefined), Q_r (exact query + bound params + declared grain/window + full
  (S,V,C,R) pins + effective and knowledge cuts; query text without values/cuts is
  incomplete), P_r (vocabulary releases + classifier mappings at exact immutable
  versions; final labels alone insufficient), I_r (registry snapshot version AND
  the evidence under every relevant PublisherIdentityBinding), A_r (source-contract
  releases for every participating provider; version label suffices only if it
  resolves to an immutable contract release), DB_r (SQLite library version/build
  identity + evidence the frozen B11 profile held), SW_r (software version resolving
  to actual computation code, not a mutable branch/tag; transitive deps included).
- Transitivity: classifier→vocabulary release, binding→evidence+receipts, source
  contract→semantic artifacts all pulled into closure.
- Completeness predicate: DependencyComplete(r) ⟺ every member present, identifiable,
  resolvable to exact version. ¬DependencyComplete(r) ⇒ ¬Reproducible(r). No
  "probably reproducible", no confidence downgrade, no recovery-from-current-state.
- Complete-but-never-replayed = "replayable", not "replay-verified".

## Replay semantics
- Replay = recompute from same admitted evidence, query, pins, cuts, mappings,
  registry snapshot + binding evidence, source-contract versions, SQLite
  artifact/profile, software version. D1=D2 ⇒ Result(D1)=Result(D2); canonical
  bytes byte-identical where a canonical representation is designated.
- Re-acquisition is NOT replay (new observation time + lineage, even if bytes
  identical). Pin migration is NOT replay (new computation). Current-state
  substitution forbidden.
- Determinism sharpened: identical closed dependency set ⇒ identical canonical
  result. Changed dependency + changed result ≠ nondeterminism. Different results
  from same closed set = determinism failure.

## B12: counterevidence presentation contract
- Every analytic claim p presents World(p) = {(S,V,C,R), effective_cut,
  knowledge_cut, scope, support, counterevidence, limitations}. Support and
  counterevidence from the same version world; cross-version only as labeled
  comparison.
- Universal: supporting evidence AND admitted counterevidence (contradicts,
  weakens, narrows, or prevents unqualified reading) AND material unresolved/
  claim-limiting evidence AND version world/temporal perspective.
- Claim-class obligations:
  - QN: closed world + exact predicate/query + window + observation span +
    exhaustion/completeness basis + executed zero-check + checked population +
    temporal bounds + limitations + receipts + pins/cuts. Any omission → INVALID.
  - Interval: both endpoints; unknown = literal UNKNOWN. No infinity substitution,
    no silent date choice.
  - Classification: classifier version AND the mapping applied.
  - Comparison: both complete pin vectors + both cuts + declared Δ.
    B12 displays the delta; B2 owns comparability.
  - "No change detected": the exact evidence windows compared (sources, spans,
    cuts). The claim is about those windows, not the world.
  - No admitted counterevidence: exact wording "no counterevidence admitted
    under these pins". Never "no counterevidence exists".
- Anti-cherry-picking: same-world rule; no silent vote (2-1 ≠ "supported");
  corrections additive to history (correction shown alongside, never instead of);
  recency ≠ deletion; preferred source ≠ deletion; UNKNOWN/coverage limits survive
  the renderer; presentation monotone w.r.t. epistemic strength (shorter allowed,
  stronger-than-entailed forbidden).
